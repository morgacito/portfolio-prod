# Portafolio - Produccion

Este repositorio contiene la version compilada y lista para produccion de **Portfolio**.

## Estructura
* La raiz del repositorio contiene los archivos estaticos compilados del **Frontend (React/Vite)**.
* El directorio php/ contiene el codigo del **Backend (PHP)** para el envio de correos de contacto.

> [!IMPORTANT]
> El archivo php/config.php que contiene las credenciales de correo electronico no se almacena en este repositorio. Debe ser configurado manualmente en el servidor de hosting. Puedes usar [php/config.example.php](php/config.example.php) como plantilla.
